# HenryKnows WebMCP Demo Video Runbook

Target length: 2:40-2:50. Hard limit: under 3:00.

## Core Idea

Your agent already has your context. HenryKnows knows the rules. WebMCP lets them work together.

Use one genuine end-to-end run. Shorten waits in editing, but do not assemble tool outputs from different cases. Place a small `Fictional student scenario` caption on the first demo frame.

## Before Recording

- Use one dedicated ChatGPT Work chat for the setup and recorded interaction.
- Use the agent-first route for this take: the agent opens the deployed judging URL in its built-in browser.
- Do not click the website's `Open ChatGPT` button during this take. That website-first route creates a new chat and cannot inherit the messages in the prepared chat.
- Record at 1920x1080 with ChatGPT and the HenryKnows browser panel visible together.
- Hide notifications, personal bookmarks, unrelated tasks, and account details.
- Set readable application zoom before recording and do not change it mid-run.
- Establish the earlier student context directly in that same chat before pressing Record.
- Complete one rehearsal, reset to a fresh case, and record a second real run.
- Keep the rehearsal only as an emergency backup.

## Exact Pre-Recording Setup

In a fresh ChatGPT Work chat, send this context before recording:

> For a fictional demonstration, I am role-playing a current F-1 master's student admitted D/S. My current I-20 runs from August 25, 2022 through December 22, 2026. I expect to be in the United States and maintaining F-1 status on September 15, 2026. I plan to apply for post-completion OPT as early as I am eligible. My sister is getting married abroad on January 5, 2027. I hope to leave after graduation and return on the same SEVIS record while my OPT application is pending, but I have not settled my return date. Keep this as reported context for a later question; do not analyze it yet.

Then send this reliability instruction in the same chat:

> For my next message, open https://henryknows-webmcp.netlify.app in your built-in browser and perform a real end-to-end demonstration using its native site tools. Treat the earlier details as reported, not verified. Ask one short permission question before sharing them with HenryKnows. Record clear answers without asking permission again. Ask only genuinely consequential missing questions, help me choose dates instead of making me invent them, and give one concise recap for confirmation before the case-specific calculation. Consult HenryKnows as often as useful, run the duration-of-status calculation only after its inputs are settled, then author and save one practical student brief and one concise DSO brief. Keep the page visible and updated. Do not narrate tool names, retries, validation, or prototype policy. Say the documents are ready only after the page verifies that both are ready. Acknowledge this instruction only and wait for my next message.

After the agent acknowledges, position the window and begin recording. The setup messages remain earlier in the same chat, outside the captured segment. Do not start another chat.

## Earlier Context

Place these facts naturally in one or two messages before the recorded segment:

- Current F-1 student, admitted D/S.
- Current I-20 starts August 25, 2022 and ends December 22, 2026.
- Expects to be in the United States and maintaining F-1 status on September 15, 2026.
- Plans post-completion OPT and wants help identifying the earliest sensible filing date.
- Hopes to depart after program completion for a January 5 wedding, return on the same SEVIS record while OPT is pending, and has not settled the return date.

The agent may propose these as remembered context, but the student must confirm the consequential facts before calculation.

Student prompt:

> Use HenryKnows to help me figure out whether I can attend my sister's wedding without creating problems for my OPT.

Expected agent move:

> I remember your expected program end date, OPT goal, and wedding plan. I can open HenryKnows, show you what I am using, and ask only about anything missing or possibly outdated. Should I proceed?

Visual priorities:

- Zoom to `ChatGPT and HenryKnows are connected` and the connection pulse.

- Show the agent's concise recap and one final confirmation.

Narration after confirmation:

> Instead of making the student complete another intake form, the agent brings forward relevant context, asks only what is missing, and keeps the shared case visible for correction.

### Optional Calendar Cameo

Use this only after a successful rehearsal in which Google Calendar and HenryKnows both work in the same chat. Create one fictional calendar event for `Sister's wedding` on January 5, 2027, omit the exact wedding date from the context message, and let the agent retrieve that one fact after permission. The agent must still ask the student for the travel window; a calendar event is not permission to infer departure or return dates.

Keep the cameo to a few seconds. The point is composition: an authorized personal tool contributes context, while HenryKnows contributes specialized regulatory analysis. Google Calendar is not part of WebMCP and should not be described as such.

Narration:

> A normal website does not know the student. A personal agent does not have HenryKnows' specialized regulatory tools. WebMCP brings them together, so the student does less intake work and arrives better prepared for human advising.

## Editing Restraint

- Use two or three zoom-and-pan cues: connection, live fact collection, final documents.
- Use hard cuts or short dissolves. Avoid decorative transitions.
- Keep captions on, but correct regulatory terms and dates manually.
- Do not add copyrighted music. Clean narration is enough.
- Export at 1080p and verify the final runtime before uploading publicly to YouTube.
